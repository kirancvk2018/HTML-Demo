Project ATLAS: Design the Supervisor-Coordinated Agent System

This time, you are not simply choosing components. You must assign the right responsibilities, position the agents in a supervisor-coordinated architecture, account for enterprise data sources, and defend your execution strategy.

1 · The client brief: GlobalTech's high-risk change request

The situation

GlobalTech Manufacturing is preparing a major change to its global order-management platform. A new regional validation rule must be introduced. The rule depends on regional policy data, legacy application logic, machine-learning risk scores and the order-management user interface.

The existing engineering team cannot quickly establish which services, data pipelines, model features and user journeys may be affected. The client wants a Claude-powered multi-agent solution that can investigate the change, coordinate specialist analysis and recommend a safe implementation plan.

What the solution must achieve

  • Understand the request and break it into bounded specialist tasks.
  • Retrieve relevant code, regional policy data, model information and interface specifications.
  • Run independent reviews concurrently, but respect task dependencies.
  • Combine findings into one traceable recommendation with unresolved questions clearly identified.
  • Escalate decisions that require human judgement; never autonomously merge or deploy code.

New information from the client

  • Regional policy data is owned by a separate business system and may be stale.
  • The machine-learning risk score is advisory, not the final decision.
  • The UI team needs a clear explanation of any new validation outcome.
  • One specialist may fail or return incomplete results during peak periods.
  • Repeated calls to external systems increase latency and cost.
Your architecture challenge
Design a supervisor-coordinated system with four specialist agents and an external environment/data layer. Decide what each specialist owns, how it communicates with the supervisor, what context it needs, and where control and approval belong.
Role: Ness Enterprise ArchitectDifficulty: Intermediate+Time: 20–25 minutesDeliverable: Architecture + rationale

Terminology note: Anthropic's own agent-design writing often calls this pattern orchestrator-workers. "Supervisor" and "orchestrator" mean the same role here. Expect either term in study material.
