1. Client scenario

GlobalTech Manufacturing

GlobalTech is a multinational manufacturer with approximately 8,000 software engineers. Its legacy applications have incomplete documentation, complex dependencies and uneven test coverage. Engineers spend significant time understanding unfamiliar code, assessing change impact and preparing regression tests.

The client asks Ness to design an AI-assisted engineering solution using Claude. For a change request in its order-management application, the solution should:

  • Understand relevant code and identify impacted components.
  • Propose test cases and assess security risks.
  • Coordinate specialist work and produce one consolidated recommendation.
  • Keep engineers accountable and require approval before consequential actions.

Client constraints

  • Some tasks depend on earlier findings; others can run independently.
  • Agents need clearly bounded responsibilities.
  • Execution must stop when information is insufficient or a defined limit is reached.
  • Failures must be visible and recoverable; no uncontrolled retry loops.
  • No agent may directly merge code or deploy to production.
Your assignment: Design the architecture and explain why the selected coordination pattern fits this business problem.
