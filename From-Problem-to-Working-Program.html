02 — PDLC in Action

Follow one problem through the lifecycle: a student grade calculator.

Problem

Read three marks, calculate the average and determine the grade.

Analysis

Inputs: three marks

Process: total → average → grade

Outputs: average and grade

Design

Decompose the problem, write pseudocode, define the grade rules, then create test cases.

Implementation

marks = [80, 70, 90]
total = sum(marks)
average = total / len(marks)

if average >= 90:
    grade = "A"
elif average >= 75:
    grade = "B"
else:
    grade = "C"

Testing

Try sample data and compare the actual output with the expected result.

03 — Stepwise Refinement

Refinement progressively turns a broad idea into precise, implementable logic.

LEVEL 1 — Goal
Process Customer Order
LEVEL 2 — Major Tasks
Read order → Calculate subtotal → Apply discount → Calculate tax → Calculate final amount → Display result
LEVEL 3 — Detail One Task
IF subtotal >= 10000
  discount_rate ← 0.10
ELSE IF subtotal >= 5000
  discount_rate ← 0.05
ELSE
  discount_rate ← 0

When should refinement stop?

Stop when each step is sufficiently precise to translate into programming constructs without having to invent missing logic while coding.

Idea→Structure→Detail→Python

for number in numbers:
