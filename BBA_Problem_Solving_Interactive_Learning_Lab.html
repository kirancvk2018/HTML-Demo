1. Think Before You Code

Programming is not only about Python syntax. For a real-life problem, first understand what the user needs, identify inputs and outputs, define the rules, break the problem into smaller tasks, and then design the solution.

Problem
What are we trying to solve?
Input
What information do we need?
Process
What calculations/rules are required?
Output
What result should the user receive?

The IPO Model

InputProcessOutput
Information entering the programCalculations, decisions and rulesInformation presented to the user

Example: Student Attendance Calculator

Input: total classes, classes attended
Process: attended ÷ total × 100
Output: attendance percentage and status

Pseudocode Reference
