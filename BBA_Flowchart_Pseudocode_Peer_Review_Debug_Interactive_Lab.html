Activity 2 — Build the Pseudocode

Scenario: A shopping program accepts multiple products, calculates each item cost, adds them to a total, and displays the final bill.

Include: start, input count, initialization, repetition, input price/quantity, calculation, accumulation, output and end.

Pseudocode reference

START INPUT number_of_products total = 0 REPEAT number_of_products times INPUT price INPUT quantity item_cost = price * quantity total = total + item_cost END REPEAT OUTPUT total STOP

Activity 5 — Debug the Broken Solution

Find the logic defects in this Attendance Calculator.

START INPUT total_classes INPUT attended_classes percentage = total_classes / attended_classes * 100 IF percentage > 75 status = "Eligible" END IF OUTPUT percentage OUTPUT status STOP

Select the problems you can identify

Debugging Questions

  1. Is the percentage formula correct?
  2. What happens when total classes is zero?
  3. What happens when attended classes exceed total classes?
  4. What happens exactly at 75%?
  5. What happens below the threshold?
  6. Is status always assigned?
