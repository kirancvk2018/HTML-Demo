04 — Pseudocode → Python

Translate the algorithm's meaning into Python syntax. Do not translate words mechanically.

→

→

area ← length × width
→

DISPLAY area
→
print(area)

Pseudocode

START
READ length
READ width
area ← length × width
DISPLAY area
END

Python

length = float(input("Enter length: "))
width = float(input("Enter width: "))

area = length * width

print("Area:", area)

05 — Translate Decision Logic

The structure of a pseudocode decision maps directly to Python's conditional structure.

Pseudocode

IF average >= 90
  grade ← "A"
ELSE IF average >= 75
  grade ← "B"
ELSE IF average >= 60
  grade ← "C"
ELSE
  grade ← "F"

Python

if average >= 90:    grade = "A"elif average >= 75:    grade = "B"elif average >= 60:    grade = "C"else:    grade = "F"

Construct mapping

IF → if
ELSE IF → elif
ELSE → else
Key rule: preserve the order and meaning of the decisions while translating.

06 — Translate Loop Logic

A loop in pseudocode becomes a Python loop with the same execution logic.

Pseudocode

START
total ← 0

FOR each number in numbers
  total ← total + number

DISPLAY total
END

Python

numbers = [10, 20, 30, 40, 50]

total = 0

for number in numbers:
    total = total + number

print("Total:", total)

Problem: Positive, Negative or Zero

A program reads a number and should display whether it is positive, negative or zero.

Buggy pseudocode

READ number

IF number > 0
  DISPLAY "Negative"
ELSE IF number < 0
  DISPLAY "Positive"
ELSE
  DISPLAY "Zero"

1. Identify the bug

2. Correct Python

number = int(input("Enter a number: "))

if number > 0:
    print("Positive")
elif number < 0:
    print("Negative")
else:
    print("Zero")

3. Test the logic
